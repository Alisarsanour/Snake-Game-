# 🐍 2D Classic Snake Game

A classic 2D Snake game developed in **Python** using the **Turtle graphics** library, featuring real-time collision detection, dynamic score tracking, and responsive controls.

---

## 🎮 Game Controls & Guidelines

* **Movement Controls:**
  * ⬆️ **Up Arrow / W:** Move Up
  * ⬇️ **Down Arrow / S:** Move Down
  * ⬅️ **Left Arrow / A:** Move Left
  * ➡️ **Right Arrow / D:** Move Right
* **Gameplay Rules:**
  * Eat the food to grow longer and increase your score.
  * Avoid running into walls or the snake's own tail (collision triggers Game Over).

---

## 📌 Key Features

* **Real-Time Collision Detection:** Instant tracking for boundary limits and self-intersections.
* **Scoreboard System:** Live score updates and high-score tracking.
* **Modular Code Structure:** Clean separation of concerns (Snake, Food, Scoreboard, Game Loop).

---

## 🛠️ Tech Stack & Concepts

* **Language:** Python 3
* **Graphics / UI:** Python Turtle Graphics Library
* **Core Concepts:** Object-Oriented Programming (OOP), Event-Driven Programming, Game Loop Mechanics.
